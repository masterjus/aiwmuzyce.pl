## ⚡ Cechy projektu & Architektura

- **Estetyka Cyber-Neural HUD**:
  - Pasek telemetryczny HUD z żywym zegarem czasu rzeczywistego (CET) oraz wskaźnikiem statusu węzła.
  - Tło z interaktywnym canvasem (sieć neuronowa cząstek reagująca na kursor).
  - Trójwymiarowa karta holograficzna (3D tilt) z oficjalnym logo cyber-głowy Futuropolis.
  - Laserowa szyna harmonogramu (7 Aktów) rozświetlająca się w miarę scrollowania strony.
  - Opcjonalny syntetyzator dźwięku UI (Web Audio API) dla futurystycznych efektów telemetrycznych.
- **Czysta implementacja**:
  - Semantyczny HTML5 z metadanymi Open Graph, Twitter Cards i Schema.org Event.
  - Vanilla CSS z nowoczesnym systemem zmiennych projektowych (bez ciężkich bibliotek).
  - Zoptymalizowany, lekki Vanilla JavaScript.
- **Gotowość do publikacji w GitHub Pages**:
  - Dołączony plik `.nojekyll` dla bezpośredniego serwowania zasobów.
